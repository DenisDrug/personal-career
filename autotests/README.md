# Автотесты безопасности и нагрузки

Тесты в этой папке работают локально и не обращаются к Telegram, сайтам вакансий или production-серверу.

## Запуск проверок

```bash
./.venv/bin/python -m pytest -q -p no:cacheprovider autotests
```

## Локальный нагрузочный сценарий

Сценарий имитирует параллельную обработку вакансий matcher-ом. Сетевые запросы и отправка сообщений отключены:

```bash
./.venv/bin/python autotests/load_scenario.py --users 50 --jobs 100 --workers 8
```

Параметры можно увеличить для проверки локальной машины. Результат содержит количество обработанных матчей,
ошибок и время выполнения. Это не является нагрузочным тестом production Telegram API.

## Что проверяется

- отсутствие секретов и локальных баз среди tracked-файлов;
- ограничение размера входного резюме и распакованного DOCX XML;
- работа фильтра доступа и формата вакансий без внешней сети;
- устойчивость matcher-а при параллельном синтетическом burst-нагрузочном тесте;
- корректное закрытие локального Storage.
